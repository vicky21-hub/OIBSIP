# Demo Video Script (about 60–90 seconds)

## Opening title card (first 2 seconds)
Show:
- Your full name
- Android App Development Track
- Task 4 — Quiz Application

## Walkthrough
1. Launch QuizMaster and show the welcome screen.
2. Explain that the app is built with Java and XML in Android Studio.
3. Tap Start Quiz.
4. Show the question counter, progress bar, and four answer choices.
5. Select one correct answer and show green feedback plus the explanation.
6. Select a wrong answer on the next question and show red feedback plus the correct option.
7. Continue through the quiz. You may speed up the recording between questions, but show enough interaction to demonstrate the flow.
8. Show the final score, correct count, incorrect count, and percentage.
9. Tap Restart Quiz and show that a fresh attempt begins.

## Suggested narration
"Hello, my name is [Your Full Name]. This is my OASIS INFOBYTE Android App Development Task 4, QuizMaster. I developed this application using Java and XML in Android Studio. It contains 15 offline general knowledge questions, displays one question at a time, provides instant correct and incorrect answer feedback, and tracks the score. At the end, users can view their result and restart the quiz. Thank you."

## Recording checklist
- Record the real app running on an emulator or phone.
- Keep text readable and avoid notifications/personal information.
- Use your own name and actual project details.
- Do not use mock screenshots or claim features that are not implemented.
